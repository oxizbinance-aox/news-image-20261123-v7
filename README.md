## How it is built

`draw_news23_v7.py` (Python + PIL, stdlib + Pillow) draws `entry.png` from scratch —
1024×1024, 209,666 bytes. `main.ts` (Node 22, stdlib only) copies the pre-rendered
`entry.png` to the output directory and verifies it meets the limits (≤1 MiB,
≤1024×1024), printing its sha256. The render is deterministic: two runs of the draw
script and two runs of `main.ts` write byte-identical PNGs.

- `entry.png` sha256: `a14239af75e47d55ed694c0037728c006b0e9bc39188b928eae2b9246135e020`
- Density gate (RapidOCR): 45/46 story heads matched verbatim; the 46th ("Sparta II")
  is present but OCR reads "II" as "Il"; all 8 regions, map, both charts, data strip
  and the date verified in OCR text. Ink coverage 0.138, 776 OCR words.
- Layout gate (PIL bounding boxes): 155 text boxes, 0 overlaps, 0 out-of-bounds — PASS.
- Self-judge vs v6: density 46 vs 36 (WIN), breadth 8 regions incl. Latin America 4 +
  Africa 5 vs 7 regions, 0 Latin America, 1 Africa (WIN); legibility and design are
  close — v6's roomier grid and darker masthead edge v7 narrowly on those two.
  Vs NI20 top-3 (leaderboard titles): #3 carries 32 stories / 6 regions — v7's 46/8
  beats it on density and breadth; the top-3 artifacts themselves could not be fetched
  visually in this session (API endpoint failed, no live browser), so the visual
  side-by-side vs NI20 is left for the submit agent on the box.
- Determinism: `main.ts` run twice → identical sha256 (see above); draw script re-run →
  identical sha256.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # copies entry.png to out/
```
